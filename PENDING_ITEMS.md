# Pending Items: Pet Health Tracker — Android

Companion to `pethealthapp/PENDING_ITEMS.md`. Open questions/follow-ups specific to the Android rewrite.

## Decisions made
See MODULE_PROGRESS.md "Architecture decisions" for the full record: Flutter (not Kotlin) for cheap future-iOS optionality, native rewrite (not Chaquopy/Python-bridge) since `core/`'s business logic is modest enough that duplication is cheaper than a permanent bridge dependency, `drift` (not raw `sqflite`) for typed schema parity, SAF (not deferred, not a provider SDK) for Android sync, new separate repo, package ID `com.kevinbrown.petsalud` (renamed 2026-07-29 from the original `com.kevinbrown.pethealthtracker` placeholder — still a placeholder, publisher identity not finalized).
